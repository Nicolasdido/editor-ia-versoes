# Política de Privacidade — Editor IA

Última atualização: 29 de outubro de 2026

O Editor IA roda no computador do usuário. Ele não tem servidor próprio e não envia os dados do usuário para
o desenvolvedor.

**O que o programa guarda, e onde.** Somente no computador do usuário: os projetos e vídeos, as gravações
de voz, e as autorizações ("tokens") das contas que o usuário conectar (YouTube, Instagram, TikTok). Nada
disso é enviado ao desenvolvedor.

**Dados das redes sociais.** Com a autorização do usuário, o programa usa as APIs oficiais para: ler o nome
da conta conectada (para mostrar qual está ligada) e publicar os vídeos que o usuário mandar publicar. No
TikTok, os escopos usados são `user.info.basic` (nome de exibição da conta) e `video.upload` /
`video.publish` (enviar o vídeo). O programa não lê mensagens, seguidores nem outros conteúdos da conta.

**Serviços de terceiros.** Ao publicar, o vídeo e o texto do post vão para a rede escolhida (YouTube,
Instagram ou TikTok), conforme as políticas de privacidade delas. Algumas funções opcionais usam serviços
externos (por exemplo, a voz de narração da Microsoft e a busca de dados de anime no AniList).

**Como apagar.** O usuário pode desconectar as contas no programa (o token é apagado do computador) e
revogar o acesso nas configurações de cada rede. Desinstalar o programa e apagar a pasta de dados remove
tudo o que ele guardou.
